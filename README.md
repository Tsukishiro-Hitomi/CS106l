# CS106L — Standard C++ Programming

Stanford CS106L 课程作业实现。

| 作业 | 主题 |
| --- | --- |
| `assignment0` Setup | 环境与编译工具链配置 |
| `assignment1` SimpleEnroll | 流与字符串处理：解析课程 CSV 并按条件检索 |
| `assignment2` Marriage Pact | STL 容器与迭代器：`set` / `map` / `queue` 的选型与使用 |
| `assignment3` Make a Class | 类的设计：构造函数、成员函数与运算符重载 |
| `assignment4` Ispell | 拼写检查器：模板、lambda 与 STL 算法 |
| `assignment5` Treebook | 特殊成员函数：拷贝 / 移动构造、赋值运算符与 RAII |
| `assignment6` Explore Courses | 泛型编程：`<algorithm>`、`<optional>` 与模板类型推导 |
| `assignment7` Unique Pointer | 智能指针：手写 `unique_ptr`，理解移动语义与所有权 |
